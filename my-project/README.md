# ElectroStreet

ElectroStreet is a React + Vite + Tailwind EV car-sharing frontend.

## Direction

The project uses the original light website direction:

- light theme;
- white background;
- red as the main brand accent;
- clean modern layout;
- no public dark-mode direction;
- no Admin item in the public Navbar.

The admin panel is planned as a separate backend page, not as a section of the public frontend navigation.

## Product Scope

The product direction remains EV car-sharing:

- vehicle data;
- vehicle statuses;
- reservation;
- active ride flow;
- charging;
- pricing;
- user balance and trip history.

## Current Stack

- React
- Vite
- Tailwind
- AOS
- react-icons
